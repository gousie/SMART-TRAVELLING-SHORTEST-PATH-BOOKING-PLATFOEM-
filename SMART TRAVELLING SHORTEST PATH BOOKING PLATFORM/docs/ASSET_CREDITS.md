# Web photography and font credits

The interface uses **real web-sourced photographs**, not AI-generated images. Assets are downloaded, converted to WebP and hosted locally so the app is independent of live search thumbnails and hotlink restrictions.

Google Images is a discovery/search service, not an image license or a stable production background endpoint. This project does **not** scrape Google Images or claim that a photo belongs to Google.

## Typography

**DM Sans** variable font from Google Fonts: https://github.com/google/fonts/tree/main/ofl/dmsans . It is locally served. The SIL Open Font License is included as `railora/static/fonts/OFL.txt`.

## UI assets

The train mark, route illustration and lightweight line icons are inline SVGs created for this project. NiceGUI/Quasar supplies its own browser renderer and standard Material Icons. ECharts supplies local chart rendering through NiceGUI.
